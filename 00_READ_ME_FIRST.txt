================================================================================
STEP 1: GET YOUR API KEY (2 minutes)
================================================================================

Go to: https://makersuite.google.com/app/apikey

1. Click "Create API key"
2. Copy the key (looks like: AIzaSy...)
3. Keep it in clipboard for next step

================================================================================
STEP 2: EDIT .env FILE (1 minute)
================================================================================

Option A (Easiest):
   - In file explorer, find the .env file in this folder
   - Right-click → Edit
   - Find: GEMINI_API_KEY=your_gemini_api_key_here
   - Replace with your key from step 1
   - Save and close

Option B (PowerShell):
   - Type in PowerShell: notepad .env
   - Replace the API key
   - Save (Ctrl+S)
   - Close

================================================================================
STEP 3: START THE APP
================================================================================

Choose ONE method:

METHOD A - EASIEST (Windows File Explorer):
   - Find "start.bat" in this folder
   - Double-click it
   - Wait for windows to open
   - Browser opens to http://localhost:8501

METHOD B - PowerShell (If Method A doesn't work):
   - Open PowerShell in this folder
   - Run: .\start.ps1
   - Or follow COPY_PASTE_COMMANDS.md

METHOD C - Manual (Most control):
   - See MANUAL_START.md for detailed steps
