AI SALES VOICE AGENT - COMPLETE WORKFLOW & TECH STACK
================================================================================

PROJECT: TechStore AI Sales Voice Agent
VERSION: 2.0 (Updated)
DATE: November 2026

OVERVIEW
================================================================================
Autonomous AI sales agent for TechStore that handles real-time voice
conversations, qualifies leads, books appointments, and generates call
summaries. Built as a continuous call experience where customers speak
naturally and the agent responds with voice.

================================================================================
TECH STACK
================================================================================

BACKEND FRAMEWORK
  - FastAPI (Python)
    * Async request handling
    * Auto-generated API docs at /docs
    * Type-safe with Pydantic validation
    * 25+ REST endpoints
    * Port: 8000

AI & LANGUAGE MODEL
  - Google Gemini 3.8 Flash (via google-genai SDK)
    * Model: gemini-3.8-flash
    * Multi-turn conversation with full context history
    * Product catalog embedded in system prompt
    * 3x retry logic on 503/UNAVAILABLE errors
    * 10 second timeout with smart keyword fallback
    * 512 max output tokens for fast responses

SPEECH PROCESSING
  - OpenAI Whisper (Speech-to-Text)
    * Model: base
    * Fully offline, no API key needed
    * Accepts WAV audio from browser mic
    * Returns transcribed text

  - pyttsx3 (Text-to-Speech)  [REPLACED gTTS]
    * Offline TTS engine using Windows voices
    * No internet connection required
    * Generates real MP3 audio (250KB+ per response)
    * Threading timeout: 10 seconds
    * Why replaced: gTTS required internet and kept timing out

KNOWLEDGE RETRIEVAL (RAG)
  - LangChain + ChromaDB + HuggingFace
    * Sentence Transformers: all-MiniLM-L6-v2
    * 8 laptop products indexed as vectors
    * Semantic search on customer queries
    * Top 3 matching products injected into Gemini prompt

DATABASE
  - SQLite (Development) → PostgreSQL (Production)
  - ORM: SQLAlchemy

  Tables:
    customers       - name, email, phone, budget, requirements,
                      buying_timeline, lead_status, sentiment
    conversations   - customer_id, message_type, content, timestamp
    appointments    - customer_id, appointment_date, reason, status
    call_summaries  - customer_id, summary, requirements, budget,
                      sentiment, lead_classification

FRONTEND
  - Streamlit (Python)
    * Continuous call UI (not tabbed dashboard)
    * Chat bubbles (WhatsApp style)
    * Auto-playing voice responses
    * Beautiful summary cards
    * Port: 8501

SENTIMENT ANALYSIS
  - TextBlob (offline, keyword-based)
    * Polarity scoring
    * Positive / Neutral / Negative classification

CALL SUMMARY GENERATION
  - Fully offline (no Gemini needed)
    * Extracts budget from conversation
    * Detects requirements via keywords
    * Identifies products mentioned
    * Calculates sentiment
    * Generates structured summary report

================================================================================
COMPLETE CALL WORKFLOW
================================================================================

STEP 1: SETUP SCREEN
  - User selects existing customer or creates new one
  - Customer info displayed (name, status, budget)
  - Click "Start Call" button

STEP 2: CALL STARTS
  - Full screen call UI opens
  - Shows customer name and exchange counter
  - Chat area displays conversation bubbles

STEP 3: VOICE INPUT
  Customer clicks mic → Records message
       ↓
  Audio (WAV) sent to POST /api/transcribe
       ↓
  Whisper transcribes audio to text
       ↓
  Text shown in chat bubble (green, right-aligned)

STEP 4: AI PROCESSING
  Transcribed text sent to POST /api/chat
       ↓
  RAG searches ChromaDB for matching products
       ↓
  Gemini 3.8 Flash called with:
    - System prompt (agent persona + product catalog)
    - Full conversation history
    - Current message + product context
       ↓
  If Gemini fails (503): retry 3x with 2s delay
  If still fails: smart keyword fallback response
       ↓
  Agent response text returned

STEP 5: VOICE OUTPUT
  Agent response sent to POST /api/text-to-speech
       ↓
  pyttsx3 generates MP3 audio (offline)
       ↓
  Audio returned to frontend
       ↓
  st.audio() plays automatically (autoplay=True)
       ↓
  Customer hears agent speaking

STEP 6: REPEAT
  Mic resets for next recording
  Customer speaks again
  Cycle repeats (continuous call)

STEP 7: QUICK ACTIONS (During Call)
  Qualify Lead    → POST /api/qualify-lead
                    Scores customer Hot/Warm/Cold
                    Displays colored badge result

  Book Appointment → POST /api/appointments
                     Creates appointment for next day
                     Shows confirmation card

  View Summary    → POST /api/call-summary
                    Generates offline summary
                    Opens dedicated summary screen

STEP 8: CALL SUMMARY SCREEN
  Displays:
    - Metric cards: Exchanges, Sentiment, Budget
    - Section cards with black text:
      * Overview
      * Customer Requirements
      * Products Discussed
      * Conversation Highlights
      * Next Steps
    - Back to Call or End & New Call buttons

================================================================================
LEAD QUALIFICATION ALGORITHM
================================================================================

  Input: budget, buying_timeline, requirements_match, sentiment

  Scoring:
    Budget > 500       → +3 points
    Budget > 0         → +1 point
    Timeline: today/this week → +3 points
    Timeline: this month      → +2 points
    Timeline: this quarter    → +1 point
    Requirements match (0-10) → 0-2 points
    Positive sentiment        → +2 points
    Negative sentiment        → -2 points

  Classification:
    Score >= 7  → HOT  (ready to buy, priority follow-up)
    Score >= 4  → WARM (interested, needs nurturing)
    Score <  4  → COLD (low intent)

  Keywords         → Response Topic
  laptop/buy/need  → Full product recommendations with specs/prices

  video/edit       → Creator laptops (Dell XPS 15, MacBook Pro)
  business/office  → Business laptops (ThinkPad, HP Spectre)
  appointment/book → Scheduling demo session

  default          → Open-ended clarifying question

================================================================================
KEY ISSUES RESOLVED DURING DEVELOPMENT
================================================================================

  1. gTTS timing out
     Problem:  gTTS requires internet, kept hanging
     Fix:      Replaced with pyttsx3 (fully offline Windows TTS)

  2. Gemini 503 errors
     Problem:  API overloaded, returned error string not exception
     Fix:      Changed send_message to raise Exception on failure
               Added 3x retry with 2s delay on 503
               Smart keyword fallback when all retries fail

  3. Duplicate Streamlit keys
     Problem:  Multiple elements sharing same key caused crashes
     Fix:      Unique keys using counters and version suffixes

  4. Voice not auto-sending after transcription
     Problem:  Transcribed text was set but send button not clicked
     Fix:      Rewrote voice flow to auto-process after transcription

  5. Summary showing API quota error (429)
     Problem:  Gemini quota exhausted for summary generation
     Fix:      Replaced with fully offline local summary generator
               Extracts budget, requirements, products, sentiment
               from conversation without any API calls

  6. Import errors (backend.app vs app)
     Problem:  Running from wrong directory caused import failures
     Fix:      Always run uvicorn from backend/ directory

  7. Frontend timeout on chat
     Problem:  15s timeout too short for Gemini + TTS
     Fix:      Increased all frontend timeouts to 30s
